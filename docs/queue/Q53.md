# Release v0.2.0 with the unshipped vulnerability and defect fixes

Blocked by [Q50](Q50.md). The only release is v0.1.0 from 2026-07-15, so everyone installing today gets an image without the fixes merged since.

At 1be389d there were 28 commits since that tag. They include fixes for `govulncheck` advisories in the Go standard library, `x/net`, grpc and otel, plus the PDB and `image.digest` fix (Q39) and the optional admission policy sample.

The cost grows with each new install, so if the blocking defects slip, release the vulnerability fixes first and follow with v0.2.1. Whether any of those advisories is reachable from the controller was not assessed. Follow `docs/development/releasing.md` and bump `website/release.json`.
