# Fix the docs navbar overflowing a 320px viewport

Every docs page scrolls sideways on a narrow phone, and the navbar's search icon is cut off. Measured 2026-11-04 in a local build of the docs site: at a 320px viewport the page is 75px wider than the screen on both the runbook and the backlog page, with no overflow at 1440px.

WCAG 1.4.10 sets 320px as the width content must reflow to. Only those two pages were measured, and the element that owns the overflow has not been confirmed. The custom navbar title in `website/.vitepress/theme/CustomNavBarTitle.vue` is the first suspect. Find the owner with a render check, fix it, and consider adding the 320px check to the website workflow.
