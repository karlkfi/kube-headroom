# Ship the quota preflight check the design promises

Design section 8.3 says to ship the `limits.cpu` quota rule as a preflight check, but operators only get a command to copy from the runbook. A namespace that fails it shows up later as resize 403s after enrollment.

Ship a runnable check over ResourceQuota and LimitRange in the namespaces about to be enrolled, and have the runbook call it. A script is the likely shape; a controller warning would also cover namespaces enrolled later. Read from the docs and not run.

`docs/design.md:322:Ship this as a preflight check` is the promise.
