# Protect main and enable Dependabot alerts

Nothing stops a red or unreviewed change reaching `main`, and known-vulnerable dependencies raise no alert. Measured 2026-11-04: the branch protection API returned 404 "Branch not protected" and the Dependabot alerts API returned 403 (disabled). Dependabot version-update PRs do arrive, which is separate from alerts.

**Ask:** what turns on Karl is that repository settings are his to change, and that requiring reviews or checks changes how he merges his own PRs.

Several workflows here are path-filtered, and a required check that never runs blocks a PR, so only always-running checks can be made required. Decide which checks those are as part of the same change.
