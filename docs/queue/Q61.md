# Add the kubectl headroom explain plugin

**Demand:** an operator or tenant asks for per-pod arithmetic that the status annotation and dashboard do not answer.

The design lists this plugin for Phase 2 and nothing has been built. The status annotation already carries the inputs, so waiting costs little. `docs/design.md:317:kubectl headroom explain` describes it.
